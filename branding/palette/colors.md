# TorqOS palette

| Name | Hex | Use |
|---|---|---|
| Graphite | `#101216` | Dark ground, app-icon tile |
| Ink | `#15171B` | Text and one-colour marks on light |
| Paper | `#F3F2EE` | Light ground |
| Torque | `#FF7A1A` | Accent on dark (ring, "OS") |
| Torque on light | `#E2620B` | Accent on light grounds |
| Foreground | `#ECEDEF` | Text and prompt on dark |
| Steel | `#8A93A3` | Secondary text on dark |
| Slate | `#5B6270` | Muted UI elements |
| Signal green | `#7EE2A8` | "OK" states (verified, secure) |

Terminal: torque ≈ `38;5;208` (256-colour), white `97`.

Type: **Space Grotesk** Bold (wordmark, headings) · **JetBrains Mono** (CLI, code). Both are SIL Open Font License.
